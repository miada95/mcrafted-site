# M Crafted website

Design preview for the new M Crafted site: luxury personalized gifting and live engraving, Tampa Bay.
*Thoughtfully curated. Uniquely yours.*

This is a **preview** to agree on the look and the homepage layout before choosing the store platform.
It is not the live site, and the inquiry form doesn't send anything yet.

## View it

Open `index.html` in a browser. No build step.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The homepage, following section 5 of the design brief |
| `styles.css` | Colors, fonts, and layout. Colors are sampled from the logo and set at the top of the file |
| `images/` | Logo, monogram, and brand images from M Crafted |
| `brief/design-brief.md` | M Crafted's website design brief |
